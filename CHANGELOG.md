# Changelog

## 0.1.0 — 2026-07-26

Initial release.

- Multi-user auth with first-run setup wizard, session cookies, admin user
  management, self-service password change
- Exercise library: 873 bundled exercises (free-exercise-db) + custom
  per-user exercises with search/filters
- Routines with per-exercise targets; weekly + dated calendar scheduling
- Live workout sessions: prefilled targets, previous-session hints, rest
  timer, warmup sets, history with editable past sessions
- Stats: personal records, estimated 1RM (Epley), strength progression,
  weekly volume
- Food library with Open Food Facts lookup (name/barcode); daily log with
  per-meal macros, serving multipliers, copy-day; calorie/macro targets
- Dashboard (food, workout, water, weight) and progress charts
- Body measurements and water tracking
- Single-container Docker deployment, SQLite in a mounted volume, automatic
  migrations, admin backup download
